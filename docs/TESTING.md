## 修复过的检查失败

测试适配器曾有调用参数和 DO 绑定类型错误，均已修复并通过最终 typecheck。并发登录测试最初强制要求一次 429，但本地 workerd 实际串行处理并返回两次 200；已修正断言，并增加直接重叠派生限流回归。生命周期测试初次 10/11 通过，失败仅是错误码断言与既有编码校验器不符（空封套返回 encoding_invalid）；修正断言后新增回归全通过。一次未提升权限的 tsx 调用因临时 IPC socket 被 sandbox 拒绝，使用已批准的测试权限重新运行成功。Workers 重复注册曾因 RPC 不保留自定义 Fault 类型返回 500；已改为显式结构化 status/error，真实 workerd 回归恢复 409。SMTP 测试的 Buffer 类型与 Workers 全局类型冲突已修，类型检查通过。环境大密文 HTTP 测试首次错误地要求双最大密文在 1 MB 账号容量下成功，完整检查曾为 75/76；已分为超过 100 kB 的合法成功案例和双最大密文容量拒绝/原子回滚案例，未提高容量或降低密码/密文参数。此前 77 项检查无失败。通知 workerd 测试曾等待标准 WebSocket close 事件五秒超时：真实关闭帧已送达、代理 TCP FIN 延迟。最终回归直接通过 ws Receiver 校验 4003 关闭帧，没有将 FIN 或标准 close 事件宣称通过；当时完整 90 项检查无失败。新增 v2 初测曾误读向量字段名和未排序 authority 的父节点，修正测试后通过；合成重置只改 generation 被真实可信根签名检查拒绝，已修测试为清除旧 vault。最新完整 109 项检查无失败。
