# 服务端验证记录

记录日期：2026-10-02。测试只使用临时目录、合成账号和固定合成密钥，没有使用用户真实凭据、环境变量或发送真实邮件。

## 已通过

- `mise run check`：typecheck 与 build 通过；21 项测试全部通过，0 失败、0 跳过，最后一次总耗时约 12.9 秒。包含 Go/TS 静态签名向量、最大明文封包边界和设备会话向量。
- Node SQLite：权限/隔离、接受顺序、同内容幂等、变内容冲突、撤销后旧重试拒绝、精确到期边界、账号代际失效、事务回滚以及关闭后重新打开数据库。
- 登录与设备持钥：密码登录不能冒用已登记 reader，须 Ed25519 持钥挑战后获得不同的设备绑定 token；挑战绑定登录会话和设备，错误公钥、过期和重复使用拒绝。
- Node Argon2id：固定 SHA256 密码等价凭据、独立随机盐、64 MiB/3 次/并行度 1；正确凭据通过、错误凭据拒绝。
- Node WASM 与 Workers noble/hashes Argon2id 相同参数双向验证通过。
- 实际本地 workerd：SQLite Durable Object 写入、持久序号拉取、D1 仅目录路由、设备会话要求通过。使用固定公开合成 dummy 验证值保持未知账号等成本验证，64 MiB/3 次，最后一次首次登录实测约 1332 ms；同机多轮约 1.3–2.6 秒。这不是线上 CPU/内存配额验收。测试 Miniflare 4.20260730.0 使用 2026-07-30 兼容日期；项目配置目标日期为 2026-10-02，仍需目标版本和线上资源验收。
- `mise exec -- pnpm build`：Node 生产源码构建通过；测试夹具不进入 dist。
- Workers 密码派生资源准入：真正重叠的 64 MiB 派生返回受控限流；本地 workerd 同时到达的两次登录实际串行成功，参数没有降低。未知邮箱也进行相同参数验证。
- Wrangler 4.147.0 生成配置绑定类型成功；`wrangler deploy --dry-run --autoconfig=false` 本地打包通过，没有上传或部署。
- Docker 29.4 / OrbStack：镜像本机构建成功。`python3 tests/docker-smoke.py` 验证随机隔离卷中的合成空账号注册、容器重启后登录和账号 ID 保留、非 root 进程、`/data` 权限 0700、拒绝远程明文绑定。没有发布端口，创建的测试容器和卷已清理。
- SMTP 配置测试：仅 465 TLS / 587 强制 STARTTLS，禁 debug/logger；只检查配置，没有网络投递。
